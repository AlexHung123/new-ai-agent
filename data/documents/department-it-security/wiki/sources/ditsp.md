# Source summary — CSB Departmental IT Security Policy and Guidelines

Departmental instrument for Civil Service Bureau. Title as printed: *Departmental IT Security Policy and Guidelines for Civil Service Bureau*. First issue **May 2006**; this compilation **July 2008 (version 1.2)**. Prepared by Unisys China/Hongkong Ltd; endorsed by CSB Analyst/Programmer II; authorised by CSB System Manager. Raw file: `MinerU_markdown_Departmental_IT_Security_Policy_and_Guidelines_2090718443034923008.md` (~2,716 lines). This wiki does not edit that file.

DITSP is **not** a volume of the Government Regulations. It sits under Security Regulations (Volume 5) and the government-wide Baseline IT Security Policy [S17] / IT Security Guidelines [G3]. See [[00-introduction]].

## Force

Part II “constitutes the IT Security Policy that all users in Civil Service Bureau (CSB) shall observe and follow” (Part II intro). Part III “provides the guidelines for deploying and enforcing” that policy. Contravention may attract disciplinary action under the Public Service (Administration) Order 1997 for civil servants, and contract termination for non-civil-service contract staff (DITSP s.6.1.10–6.1.11). Staff handling classified systems shall undergo an integrity check under CSB Circular 17/94 (s.6.1.15).

## Reading the conversion

- Repeated running headers and TOC dots are not new sections.
- Figures 5.1 (IT security organisation), 21.1 (incident workflow), and 21.2 (ISIRT information flow) are images; roles are taken from the surrounding captions, not invented boxes.
- Footnote bodies for superscripts 2–12 are missing. Level II / III physical standards are therefore cited as SR / Security Bureau documents, not reconstructed here.
- Title-page copyright line prints “HKSKAR”.
- HTML entities (`&#x27;`) and `<eq>` markers in the s.17.1 table are reconstructed as ordinary English.
- “Division DITSO” is the booklet’s term for the three site officers; “DITSO” in CSB IT security documents means them (s.5.3 note).
- Appendix C of **this** booklet is file sharing. The Preliminary Information Security Incident Report Form is Appendix C of the separate *Information Security Management Framework for CSB* (s.21.3) — a different instrument.
