## Definitions (DITSP s.4.1)

Taken from SR, S17, G3, and G54.

| Term | Meaning |
| --- | --- |
| Information System | Electronic system that processes data by IT — computers, servers, workstations, terminals, storage media, communications devices, network resources |
| Availability | Systems should be available to users at a given or specified time |
| Integrity | Only authorised persons may change information stored or processed |
| Confidentiality | Only authorised persons may know or gain access to that information |
| [[information-security|Information Security]] | Preservation of confidentiality, integrity, and availability |
| [[classified-information|Classified Information]] | Categories in **SR Chapter III** |
| Security Risk Assessment | Evaluating IT-related security risks; a baseline for change since the last assessment |
| Security Incident | Any event or vulnerability that could threaten CIA of a system or information resources |
| Malicious codes | Programs that cause an undesirable effect (viruses, worms, Trojans, logic bombs, spyware) |

## CSB framework (DITSP s.5)

Section 5 is taken from the CSB *Information Security Management Framework*. **Figure 5.1** is captioned “The CSB IT Security Organization”; it is an image in this conversion. Roles below are from the surrounding text, not reconstructed boxes. Compare [[compare-roles]].

**[[dso|Departmental Security Officer]]** (s.5.1). SR requires a DSO for security duties in CSB. The DSO has overall responsibility for IT security management and acts as executive: direct and enforce measures; provide resources; ensure participation at all levels and support staff; discharge all aspects of CSB security; advise on setting up and reviewing the security policy.

**[[itmu-security-team|CSB ITMU Security Team]]** (s.5.2). Central coordination and technical support to **three CSB divisions**. Technical advice to the DSO and Division ISIRTs on information security incidents.

**[[ditso|Division DITSO]]** (s.5.3). S17 requires each bureau/department to appoint a Departmental IT Security Officer. CSB appoints a **Division DITSO for three site-specific CSB divisions**, each leading IT security at that division’s site. Duties: an information-protection programme for the division; lead establishment, maintenance, and implementation of policies, standards, guidelines, and procedures; promote awareness; coordinate with other bureaux/departments and CSB divisions; ensure security risk assessments and audits at least every **two years** and as necessary; initiate investigation and rectification on breach.

> **Note (DITSP s.5.3):** when DITSP says “DITSO”, it means the Division DITSOs.

**[[information-system-owner|Information System Owners]]** (s.5.4). Collators and owners of information in databases and data files. They determine security requirements, **security classifications**, usage, and protection, and lead establishment of IT security procedures for their system.

**IT Staff** (s.5.5). CSB technical staff who support management and daily operations — including IT security administrators, network and system administrators, and application development and maintenance. They implement and maintain safeguards under procedures and guidelines set by the Division DITSO and/or Information System Owners.

**Users** (s.5.6). Staff who use information on systems. They **shall be accountable for all their activities** on those systems: know, understand, follow, and apply available security mechanisms to the maximum extent possible; prevent unauthorised access to their computers and workstations.

The acronym table also lists ISMC and ITSWG; s.5 does not describe them. Do not invent those boxes from Figure 5.1.
