# Appendices A–D

Catalogue of the four appendices to DITSP v1.2 (July 2008). This page is a hub only. Detail lives on the four annex pages.

**Do not confuse DITSP Appendix C with ISMF Appendix C.** The Preliminary Information Security Incident Report Form is Appendix C of the separate *Information Security Management Framework for CSB* (DITSP s.21.3). That form is not in this booklet. Incident reporting: [[08-incident]].

## Catalogue

| Appendix | Title | What it is | Page |
| --- | --- | --- | --- |
| **A** | Extracts from the Security Regulations | SR Chapter III classifications (160–161), Chapter IV media / copying / waste (198, 210, 227), Chapter IX information systems (350–383). An **extract**, not the full SR | [[annex-security-regulations]] |
| **B** | Areas to observe when using portable electronic devices | Notebooks and removable media: policy/admin vs technical measures; personal-responsibility checklist. Added v1.1 | [[annex-portable-devices]] |
| **C** | Areas to observe when using file sharing technologies | P2P and other file sharing: [[ditso|Division DITSO]] case-by-case approval plus risk assessment. Added v1.1. **Not** the ISMF incident-report form | [[annex-file-sharing]] |
| **D** | Compliance with the Copyright Ordinance and relevant guidelines on the use of computer software | IPD Circular 3/2005; OGCIO Circular 3/2008; SAM; photocopying licence. Added v1.2 | [[annex-copyright]] |

Appendix A is the SR overlay that [[04-data]] and [[compare-classification-controls]] summarise. Appendix B is invoked whenever classified data go onto notebooks or removable media (DITSP s.17.1). Appendices C and D sit under software usage (DITSP s.19.5.1): C is the file-sharing pointer; D is the copyright/SAM pointer. See [[06-network-malware-patch]] and [[copyright-compliance]].
