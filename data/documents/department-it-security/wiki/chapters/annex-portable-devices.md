# Appendix B — Portable electronic devices

Added in **v1.1 (May 2008)**. DITSP s.17.1: when using portable electronic devices — including notebooks and removable storage media — to contain [[classified-information|classified information]], the areas in this appendix **must** be observed. Catalogue: [[annexes]]. SR overlay: [[annex-security-regulations]], [[compare-classification-controls]].

**Central control of removable storage media is a separate document** (Appendix B technical note). It is not in this booklet.

## Policy and administrative measures

- Proper [[classified-information|classification]] of data being handled.
- Complete inventory of all portable electronic devices containing classified information.
- Procure and provide portable electronic devices to staff **centrally**.
- Remind staff not to connect any **unauthorised** devices to government information systems.
- Assess the need to store classified information on the devices.
- Obtain **proper authorisation** before storing classified information on them.
- Store only the **minimal** data needed for operations.
- **Remove** classified information from the devices once finished using it.
- Devices containing classified information: keep under continuous, direct supervision when in use; store in physically protected areas appropriate to that classification when not in use.
- Detach the portable device from local computers when not attended or not in use.

## Technical measures

- Authenticate before permitting access to data stored on the device, if applicable.
- **Encrypt classified information on all portable electronic devices.** In particular, deploy removable storage media with **built-in encryption** capabilities. See [[encryption]].

[[ogcio|OGCIO]] has published, through the government intranet (ITG InfoStation), technical solutions and products that support encryption (Appendix B (e)).

## Personal-responsibility checklist

Security of classified data, including documents containing personal data, is the **personal responsibility of every government servant**. Unauthorised disclosure is not in the interests of the Government and the public. Consider these issues **before** putting personal data or classified information onto portable electronic devices.

| Step | Rule |
| --- | --- |
| **(a) Understand the risks** | USB flash memory sticks, PDAs, mobile phones and MP3 music players are risky places to store data: small, easily lost or stolen. Be particularly cautious |
| **(b) Confirm the need** | Data on a **need-to-know** basis. Ask whether you really need to store personal or classified data on the device. Alternatives: work on the data at the location where it was generated, rather than moving it; work on an internal server with the necessary security protection. Do **not** send personal or classified data through the Internet without assessing the security risks and adopting the necessary protection |
| **(c) Seek authorisation** | If you really need to store personal or classified data on a portable storage device, minimise the risk and consequences of loss and seek **prior permission on each occasion** as appropriate. Keep clear, detailed records (**when, where, what, who, how, why**) of devices that contain personal or classified data |
| **(d) Minimise the exposure** | Use a device **provided by CSB ITMU** ([[itmu-security-team]]). **Never** store personal or classified data on a **personally owned** device or PC. Do not store more data than you really need. If downloading from a database, extract only the fields and records absolutely needed (names and ID numbers removed unless absolutely required). Delete data from the device as soon as it no longer needs to be stored there |
| **(e) Safe custody and proper use** | Protect data on the device: security features including passwords, encryption, biometrics (e.g. fingerprints); store and use so the device and data are not susceptible to theft, copying or tampering; make maximum use of the relevant security features of the application software |
| **(f) Regular review** | Copying personal or classified data to a portable electronic storage device should be **one-off**, not a regular practice. If regular copying is required, arrange with the [[ditso|Divisional IT Security Officer]] a more secure way of transferring and accessing the data |
