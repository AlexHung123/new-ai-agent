# Overview — GITP Acquisition Procedures wiki

This is the compiled wiki of DPO’s booklet *Acquisition Procedures for Listing Arrangement for Government Procurement of IT Products* (GITP), version 1.3c. The raw file is `MinerU_markdown_Acqn-Procedures_(GITP)_v1.3c_2090718397556084736.md` (English PDF conversion, 546 lines; annex bodies not transcribed). You read the wiki; the agent writes it. For any question, start at [[index]], then open only the pages you need.

## One acquisition lifecycle

```
Need inside [[product-categories]]
        → write a [[brief]] (overall / group / item)
        → invite [[gitp-providers]] via [[e-ps]] only
        → [[proposal-evaluation]] (technical then price)
        → letter of acceptance → orders in the Price Validity window
        → [[acceptance-tests]] → Acceptance Certificate
        → pay ([[04-payment]]); [[warranty]] then optional [[maintenance-schemes]]
        → adverse [[cpar]] only if needed
```

The fork that decides almost everything is **value against the [[quotation-limit|SPR 220(a) quotation limit]]**. GITP is a Chapter II quotation channel. Above that limit, B/Ds must open-tender under SPR Chapter III — not this scheme. See [[compare-approving-authorities]] and [[02-acquisition]].

## Who does what

| Actor | Role |
| --- | --- |
| [[dpo|Digital Policy Office]] | Runs the listing; publishes reference products and requirements on ITG InfoStation; formerly OGCIO |
| [[gitp-providers]] | Listed suppliers who have undertaken the GITP Participation Terms; they are not exclusive |
| [[e-ps]] | The **only** invitation / proposal avenue under the scheme |
| B/D user + supplies ranks | Prepare the Brief; invite and accept by the rank tables |
| [[itmu|ITMU / Client IT Services Manager]] | Technical advice; optional evaluation panel |
| [[gitp-support-team]] | Scheme enquiries; CPAR disagreement escalation |
| Coordinating Officer (≥ ASO / EO II) | Ensures the booklet is followed ([[07-control]]) |

Capitalised terms take their meaning from Clause 1 of the [[conditions-of-contract|Conditions of Contract]] (AP s.1.1). That contract set is **not** in this compilation.

## Three structural facts

1. **Listing is not a standing contract.** B/Ds are not obliged to buy, and a GITP Provider is not obliged to sell, anything on the reference IT product list (AP s.1.2(f)). Reference specifications may be tailored inside the sub-category (AP s.1.2(g)).
2. **e-PS is exclusive.** There is no separate paper or email invitation route under GITP (AP s.1.2(h), s.3.3.4).
3. **Financial limits in this booklet auto-update** when SPR 260(a), 260(b), 220(a), 265, or 290 move (AP s.3.11). The Jan 2024 snapshot in the amendment history is **$1.36 million** for the quotation limit. Treat printed dollars as historical; the live rule is “the prevailing quotation limit”.
