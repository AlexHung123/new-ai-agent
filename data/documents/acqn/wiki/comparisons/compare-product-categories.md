# Compare — product categories A / B / C

Three major [[product-categories]] (AP s.2.2). Each product sits in **one sub-category**. A [[brief]] may address several sub-categories across categories (AP s.3.1). A5/A6 split in the source table is OCR-merged; details and caveat on the concept page.

| | **A — Network / infrastructure** | **B — Server systems** | **C — Microcomputer** |
| --- | --- | --- | --- |
| **Sub-categories** | A1–A8 (routers/switches, wireless, load balancer, security kit, network software, power, cabinet, cable) | B1–B4 (server computer, storage, system software, application software) | C1–C5 (desktop, notebook, mobile device, printer, PC software) |
| **Typical products** | Router, switch, AP, firewall, UPS, rack, cable | Server, disk/NAS/tape, OS, backup, virtualisation, mail, database, CMS | PC, notebook, tablet, phone, laser/LED printer, desktop OS, office automation |
| **Minimum invitation time** (AP s.3.3.4, unless adjusted) | **Two weeks** | **Two weeks** | **One week** |
| **GITP Support Team tel.** (AP s.9 snapshot) | 2231 5422 / 2231 4095 | 2231 5444 / 2231 5403 | 2231 5443 / 2231 5422 |
| **Same rules** | [[quotation-limit]]; invite all listed [[gitp-providers]] of the sub-category unless justified; [[e-ps]] only; SPR 350(b) specs; [[acceptance-tests]] |

Custom program work and on-site ongoing office/network support are out of scope for **all** categories (AP s.3.2.1).
