# Compare — disposal paths

Disposal is a **menu**, not a synonym for shredding (RMM 601, 625). Every path except “still in the office, still scheduled” eventually needs [[grs]] / [[grs-director]] agreement. Chapter: [[05-scheduling-disposal]].

| Path | When | Gate |
| --- | --- | --- |
| Keep in the B/D for a stated period | Business, legal or accountability need; definite period assigned first where practicable (RMM 618) | Schedule agreed with GRS Director (programme) or GARDS (administrative) |
| Permanent retention **in the B/D** | Usually only if **legislation** requires it (RMM 619) | Not a substitute for [[pro]] transfer |
| Transfer to other media, then destroy original | Microfilm, optical discs, etc. (RMM 601, 625) | Still a disposal action; original destruction needs GRS Director (RMM 605) |
| [[records-centre]] (inactive) | Reference rate no longer warrants office space (RMM 629) | RMO facilities; B/D written consent to destroy; **3-month silence** lets RMO destroy (RMM 630) |
| Destroy as having no retention value | Immediate destruction when due (RMM 625) | **No destroy without GRS Director** (RMM 605); not ad hoc (RMM 628) |
| Transfer to PRO as archives | Archivist of PRO appraises archival value; all records reaching 30 years appraised (RMM 626, 637) | GRS Director–approved schedule; PRO acceptance tests (RMM 636–639) |
| Central Preservation Library | Library collections or printed materials; send a copy of new publications (RMM 631) | Integral part of PRO; General Circular 1/2001 |
| Transfer outside Government | Function outsourced / sold / corporatised | GRS Director authority; see [[compare-custody-ownership]] |

Unauthorised removal, defacing, alteration, destruction or loss: report to the GRS Director **immediately** (RMM 606). Time-expired [[vital-records]] use these same paths (RMM 730).
