# Compare — administrative versus programme records

This is the filing **and** disposal fork. Getting it wrong either clutters the office or destroys the mission file. Chapters: [[03-classification-content]], [[05-scheduling-disposal]].

| | [[administrative-records]] | [[programme-records]] |
| --- | --- | --- |
| What they document | Common **internal administration**: finance, accommodation, procurement, establishment, personnel, etc. (RMM 418; Appendix B) | **Primary functions, activities or missions** for which the B/D was established (RMM 417) |
| Unique to the B/D? | No — common across Government | **Yes** |
| Classification scheme | **Adopt** GRS subject scheme in Publication No. 3 (RMM 418) | **Develop your own**, using Publication No. 3 — *Subject Filing* (RMM 417) |
| Disposal schedules | **GARDS**, Publication No. 4 (RMM 419, 612) | B/D-built schedules (RMM 613) |
| Whose authority? | GARDS as issued by GRS | **Must** obtain disposal authority from the [[grs-director]] via [[rmo]] (RMM 615) |
| Changes | Follow current GARDS | Agree every change with the GRS Director; lodge with RMO first (RMM 616) |

Both families still sit in one [[recordkeeping-system]] that covers **all official records** (RMM 416). Neither path waives the destruction bar in RMM 605. GARDS retention periods are **not** in this compilation.
