# Overview — Records Management Manual wiki

This is the compiled wiki of the *Records Management Manual of the Government of the Hong Kong Special Administrative Region*, 2001 with minor updates in November 2020, issued by the [[director-of-administration]]. The raw file is `MinerU_markdown_2.3.1_RM_Manual_(Eng)_2090718349128654848.md` (English PDF conversion, 1,148 lines). You read the wiki; the agent writes it. For any question, start at [[index]], then open only the pages you need.

## One records lifecycle

```
Identify functions and information needs
        → create / collect a complete [[government-records|government record]]
        → capture into a [[recordkeeping-system]]
        → [[content-classification]] + [[security-classification]]
        → use, retrieve, track; public [[records-access]] where the Code allows
        → store and protect ([[04-storage-security]])
        → [[records-scheduling]] → [[records-disposal]]
              ├─ destroy (only with [[grs-director]] agreement)
              ├─ [[records-centre]] for inactive
              └─ [[pro|PRO]] if archival
Vital records run in parallel ([[vital-records]]).
Function moves trigger [[administrative-changes]] / [[custody-ownership]].
```

The fork that decides almost everything after capture is **[[administrative-records]] versus [[programme-records]]**. Administrative records follow GRS’s GARDS scheme and schedules. Programme records need a B/D-built scheme and GRS-authorised schedules. See [[compare-admin-vs-programme]].

| Actor | Role |
| --- | --- |
| [[director-of-administration]] | Issues and amends the Manual |
| [[head-of-bd]] | Owns the departmental programme, priority and resources |
| [[drm|Departmental Records Manager]] | Day-to-day owner; normally Departmental Secretary or equivalent |
| [[grs|Government Records Service]] | Central RM and archives agency |

| Action officers | Create complete records; consult on transfers |

Companion GRS publications (not in this file) give the how-to. Catalogue: [[annex-publications]].

## Three structural facts

1. **A record is evidence, not a format.** Content + structure + context, kept in a [[recordkeeping-system]] (RMM 115–117). Extra copies, drafts (if the official copy is filed), library stock, and routing slips are [[compare-records-vs-nonrecords|non-records]]. Labelling something “personal” does not make it so if it was used in official business (RMM 413).
2. **No destruction without the GRS Director.** [[records-disposal]] is broader than shredding — retain, migrate, send off-site, or destroy — but RMM 605 is a hard bar. Unauthorised loss or alteration is reported to the GRS Director immediately (RMM 606).
3. **The Manual is a code of practices, not a Government Regulation volume.** B/Ds should follow it “as far as possible” (RMM 103). Hard bars still sit in the text. Electronic-records strategy is deferred to later GRS issuances in this compilation (RMM 107, 123).
