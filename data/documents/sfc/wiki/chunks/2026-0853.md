# 2026 · 問題 0853

> 來源：`source3.md`　總目：(37) 衞生署　綱領：(7) 公務員醫療及牙科服務　提問人：周小松議員

年份: 2026

(問題編號：0853)
總目： (37) 衞生署

分目： (-) 沒有指定

綱領： (7) 公務員醫療及牙科服務

管制人員：衞生署署長(林文健醫生)

局長：公務員事務局局長

問題：

關於公務員及合資格人士的牙科福利，政府可否告知本會：

(一 ) 「牙科服務(洗牙)先導計劃」第二期(「先導計劃第二期」)推行以來的以下資料：(i)獲邀參與人士數量、(ii)接受邀請的人數、(iii)已預約／已接受洗牙服務的人數、(iv)取消預約後沒有在限期前重新預約的人數及(v)未有依約就診的人數，並以參與人士類別(即新症或舊症)列出分項資料；

(二 ) 「牙科服務深圳試點計劃」第一期(「試點計劃第一期」)推行以來的以下資料：(i)發出參加意向書數量、(ii)獲邀參與人士數量、(iii)接受邀請的人數、(iv)已預約／已接受服務的人數、(v)取消預約後沒有在限期前重新預約的人數及(vi)未有依約就診的人數，並以參與人士類別(即新症或舊症)列出分項資料；

(三 ) 「先導計劃第二期」及「試點計劃第一期」服務意見調查所統計的(i)滿意率、(ii)投訴個案數字、(iii)投訴成因，及(iv)署方的跟進工作；

(四 ) 各間參與「先導計劃第二期」及「試點計劃第一期」的私營牙科診療機構(i)承諾提供的服務量及(ii)所收取的資助金和相關行政費用分別為何；

(五 ) 如公務員及合資格人士在接受私營牙科診療機構服務期間發現其他問題，將轉介回衞生署作跟進。自「先導計劃第二期」及「試點計劃第一期」開展以來，私營牙科診療機構轉介的個案數量為何，以及，上述個案的平均輪候時間為何；

(六)　 自「先導計劃第二期」及「試點計劃第一期」推行，舊症人士輪候下一次洗牙服務的時間縮短了多少；及

(七 ) 過去一年，公務員及合資格人士在牙科診所(包括設於醫院的口腔頜面外科及牙科診所)預約(i)牙科定期檢查、(ii)牙科跟進治療及(iii)非急症牙科專科服務的輪候時間為何？

提問人：周小松議員(立法會內部參考編號：2)

答覆：

( 一 ) 透過私營牙科診所向公務員及合資格人士提供洗牙服務的牙科服務( 洗牙 ) 先導計劃第二期 ( 下稱「先導計劃第二期」 ) ，服務期由2025年 2月 1日至 2026年 7月 31日。

截至2026年2月28日，衞生署已向約241 000人(包括約211 000名舊症人士及約30 000名新症人士)發出邀請，當中約129 000人(包括約111 000名舊症人士及約18 000名新症人士)已預約或已接受洗牙服務，整體參與率約為54%。預約後未有依約接受洗牙服務的人士共35 人(包括20名舊症人士及15名新症人士)。衞生署沒有備存取消預約後沒有在限期前重新預約的人數。

(二)　 公務員及合資格人士牙科服務深圳試點計劃第一期(下稱「深圳試點計劃第一期」)的服務期由2025年2月17日至2026年2月16日。

衞生署合共向約27 700名新症人士發出參加意向書，並向當中約3 800名表示有意參與者發出邀請。接受服務的人數合共約2 100人，整體參與率約為56%。預約後未有依約接受牙科服務的人士共41人(全屬新症人士)。衞生署沒有備存取消預約後沒有在限期前重新預約的人數。

(三 )　 衞生署持續透過問卷調查，向已接受先導計劃或試點計劃服務的公務員及合資格人士收集意見。

就先導計劃第二期，截至2026年2月28日，93%填交問卷者對計劃表示滿意。衞生署共收到19宗投訴，投訴原因包括參與計劃的私營牙科診所的安排欠妥善、診所員工的服務態度、診所主動推銷自費服務等。衞生署已跟進所有投訴，要求診所所屬的私營牙科診療機構作出改善。

至於深圳試點計劃第一期，93%填交問卷者對計劃表示滿意。衞生署並沒有收到與深圳試點計劃第一期相關的投訴。

(四)　 每間私營牙科診療機構在先導計劃第二期服務期內，每月須在旗下最少4間牙科診所合共提供最少400個洗牙名額。截至2026年2月28日，

已接受或已預約洗牙服務的人數合共約129 000人，涉及服務開支約7,700萬元。

在深圳試點計劃第一期下提供牙科服務的機構於一年服務期內須提供不少於2 000個服務名額，而最終接受服務的人數合共約2 100人，涉及服務開支約120萬元。

衞生署是透過重新調撥現有用於公務員醫療及牙科服務的撥款來支付上述兩個計劃所涉及的相關開支，因此不涉額外開支。

(五)　 在先導計劃第二期下，截至2026年2月28日，約有36 300宗由私營牙科診所轉介衞生署跟進的個案；在深圳試點計劃第一期下，衞生署需要安排跟進的個案約有970個。兩項計劃大部分需跟進個案均可於接受私營牙科服務後9個月內獲得衞生署跟進。

(六)　 自先導計劃第二期推行以來，舊症人士輪候下一次洗牙服務的時間已縮短至平均約15個月。

(七 ) 截至2025年12月31日，公務員及合資格人士在牙科診所(包括設於醫院的口腔頜面外科及牙科診所)的牙科定期檢查、牙科跟進治療及非急症牙科專科服務的輪候時間分別為12至44個月、1至52個月及6至45個月。
