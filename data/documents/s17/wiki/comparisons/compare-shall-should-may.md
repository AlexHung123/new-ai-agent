# Compare — shall, should, may

S17 s.4.2 conventions:

| Word | Force |
| --- | --- |
| **Shall** | A **mandatory** requirement. |
| **Should** | A **best practice**, which should be implemented **whenever possible**. |
| **May** | A **desirable** best practice. |

S17 is the top-level mandatory policy; G3 is the implementation standard B/Ds **shall** comply with (S17 s.2.3.2). B/Ds need to apply **enhanced** measures commensurate with determined risks (S17 s.2.1). S17 cannot waive Security Regulations. Document stack: [[compare-documents]].

## Worked examples from S17

| Force | Example | Citation |
| --- | --- | --- |
| **Shall** | All classified information **shall** be encrypted in storage irrespective of the storage media. | s.10.2.2; [[encryption]] |
| **Shall** | Head of B/D **shall** appoint a D3 (or highest directorate) [[ditso\|DITSO]]. | s.5.2.1 |
| **Shall** | B/Ds **shall** establish an IT security management unit reporting to DITSO. | s.5.2.5 |
| **Shall** | Information classified RESTRICTED or above **shall not** be stored in or processed by public cloud. | s.17.3.1; [[outsourcing-security]] |
| **Shall** | Observed or suspected incidents **shall** be reported **immediately**. | s.18.1.5; [[incident-handling]] |
| **Should** | Senior management **should** consider setting up an information security **steering committee** which reports to DITSO, or putting information security on regular management meetings. If none is set up, DITSO should undertake the committee’s responsibilities. | s.5.2.2 |
| **Should** | For staff other than civil servants, appropriate background verification checks **should** be carried out. | s.9.1.4 |
| **Should** | Backup media **should** be protected against unauthorised access, misuse, or corruption. | s.14.3.4 |
| **Should** | CONFIDENTIAL/RESTRICTED **should** be encrypted during transmission on any network as far as practicable (un-trusted is a *shall*). | s.15.2.2 |
| **Should** | All personal data **should** be classified RESTRICTED or above. | s.20.1.4 |
| **May** | B/Ds **may** appoint an IT Security Auditor to audit IT Security Administrators. | s.5.3.1 |
| **May** | Internet access through stand-alone machines, with an approval and control mechanism, where a gateway is not feasible. | s.15.1.9 |
| **May** | A higher classification than RESTRICTED for sensitive personal data. | s.20.1.4 |

“Should” is not optional colour: it is best practice to implement whenever possible. Recording a deviation is not a waiver of a *shall*.

G3 Appendix C turns selected body *shoulds* into *shalls* for [[classified-protection|Tier 2 / Tier 3]] systems. Those extras are **not** in S17. When answering “is this mandatory?”, read the S17 *shall* first; then, for implementation colour and tier extras, consult G3 separately. Overlay, do not collapse. See [[compare-tiers]].
