# 聘用條款

CSR 第 100(12) 條把公務員的僱用形式及歷史條款層層分開。實務上必須同時問兩件事：這員是按日／按月／試用／合約／長期／試任，以及屬於[[compare-appointment-terms|本地、海外、劃一還是新條款]]。後者決定[[leave|假期]]、[[passages|旅費]]、[[pension|退休福利]]及房屋計劃資格。見 [[01-appointment]]。

## 僱用形式（第 100(12)(a)–(f) 條）

| 形式 | 要點 |
| --- | --- |
| 按日聘用 | 招聘手續辦妥後，改按正式條款受聘，生效日期追溯至按日起計首日 |
| 按月聘用 | 任何一方可以一個月通知或一個月薪金代替通知終止 |
| 試用 | 擔任設定職位；通常三年；見 [[probation]] |
| 合約 | 聘書訂明固定任期；可填常額或編外職位 |
| 長期 | 試用、合約或其他適用期限屆滿後，確實聘用為常額編制、擔任設定職位 |
| 試任 | 已獲確實聘任的人員，改任截然不同職位時的固定試任期；見 [[trial]] |

## 歷史條款層（第 100(12)(g)–(j) 條）

| 條款 | 適用 |
| --- | --- |
| 本地 | 劃一條款實施前用以聘用本地公務員 |
| 海外 | 劃一條款實施前用以聘用海外公務員 |
| 劃一 | 1999-01-01 或之後、2000-06-01 之前按公務員聘用條款入職者 |
| 新 | 2000-06-01 或之後按公務員聘用條款入職者 |

本地公務員：按本地條款者；或按劃一／新條款且為香港特區永久性居民。非本地公務員：按海外條款者；或按劃一／新條款但不是永久性居民（第 100(14)–(15) 條）。

## 本地化政策（第 100(13) 條）

本地應徵者優先。非本地應徵者只在沒有完全符合資格的合適本地人選、聘用條件不能修改使本地人員優先、且聘任不牴觸《基本法》時才考慮。
