# 總覽 — 《公務員事務規例》wiki

這是香港特區政府規例第 2 卷的編譯 wiki。原料是 `csr.md`（PDF 轉出、約 2 萬行、OCR 殘缺）。你讀 wiki；代理人寫 wiki。查任何問題先讀 [[index]]，再只打開相關頁。

## 一條職業生涯

```
入職 [[01-appointment]] → 試用 [[probation]]／評核 [[appraisal]]
        → 署任 [[acting]]／晉升
        → 薪津 [[pay]]、假期 [[leave]]、醫療 [[06-medical-dental]]
        → 房屋 [[compare-housing-schemes]]
        → 品行 [[discipline]]／[[advantages]]／[[outside-work]]
        → 離職 [[compare-exit-routes]]／退休 [[pension]] 或 [[cspf]]
```

穿越所有章的分叉軸是[[appointment-terms|聘用條款層]]：本地、海外、劃一（1999-01-01 至 2000-05-31）、新（2000-06-01 起）。對照 [[compare-appointment-terms]]。

## 兩次結構斷裂

1. **1999 劃一條款**把本地／海外雙軌收束。
2. **2000-06-01 新條款**把新入職者送入[[cspf]]與[[nacs]]，並逐漸關閉舊宿舍／HFS／AAS／RAS 的大門。之後的第十一至十四章是疊在第五章總閘（第 809 條）上的計劃層，不是另一套房屋哲學。

沒有第十章。金額幾乎全在[[annexes]]，且修訂到 2026 年。
