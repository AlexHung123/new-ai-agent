# 評核報告、服務證書與最近親卡

[[01-appointment|第一章]]分頁。CSR 第 230–240 條為[[appraisal|評核報告]]；第 241–245 條為服務證書及評核證書；第 246–259 條最近親卡在目錄有題，本彙編正文缺漏。

## 摘要

所有公務員都須定期接受評核。報告記錄服務期間的工作表現和品行，用於確實聘任、實任、升職、每年增薪及個人發展等決定，因此必須詳盡、審慎。試用、試任及署理以待實任另有較密的報告周期。任何公務員不論年資或表現，即使仍在職，均可獲發服務證書。

## 評核總則與人員（CSR 第 230–233 條）

所有公務員都須定期接受評核（第 230(1) 條）。報告記錄工作表現和品行，在推薦確實聘任為可享退休金編制人員、確任職位、升職、每年增薪、個人發展等方面影響甚大，必須謹慎撰寫，盡量詳列優點和缺點。若要求把一人調職，評核中並應說明理由（第 230(2)–(3) 條；部分 OCR 殘）。必須充分詳細說明評核期間的職務（第 230(4) 條）。

**評核人員**通常須較接受評核人員高一級；即使前者署理較高職級，此要求仍適用（第 231(1) 條；字句略殘）。只應就能夠作出如實、客觀和全面評估的方面評核；不能評核的項目應據實說明。須在短時間內（例如少過六個月）評核時，應盡可能徵詢前任評核人員意見，並在報告中說明；若該員以前擔任不同職務，應就其擔任該職位時的表現另作交代（第 231(3) 條）。

**加簽人員**應對評核作出補充，例如指出評核人員「傾向於給予過高的評級」；不同意任何評核時應附加本人評語並加簡簽（第 231(4) 條）。

**覆核人員**通常為職系首長或部門首長，可轉授給適當職級人員。職責是審核近期工作表現報告，並且：評定是否適合晉升及評估潛質；表現低於可接受水平時決定補救措施；不時會見該員討論職業前途或安排這類會見；監察評核標準，並就標準是否過低向加簽或評核人員提出意見。覆核人員應對同一級別其他人有全面認識，並知道再高一職級所需才能與條件，以便公平評核（第 231(5)–(6) 條）。

**評核會見**：讓接受評核人員知悉工作表現及潛質，並協助克服弱點。所有接受評核人員均有權獲得評核會見；例外情況須在報告內寫明理由。主持會見前須讓該員閱覽整份評核報告。討論事宜須簡要記錄在報告內；主持者及接受評核人員均須在會見紀錄上簽署（第 232 條）。

因一般態度等原因以致工作散漫或未盡全力，應即當面或書面提出忠告（第 233 條；字句殘）。

## 周期、表格與保管（CSR 第 234–240 條）

中央職系的每年度評核，由下列主管當局每年發通告要求提交（第 234(1) 條；表內職銜以 11/2022、12/2024 修訂為準）：

| 職系 | 主管當局 |
| --- | --- |
| 政務主任 | [[scs|公務員事務局局長]] |
| 行政主任；私人秘書（一級及二級除外） | 一般職系處長 |
| 法定語文主任；即時傳譯主任；繕校員 | 公務員事務局副秘書長 1 |
| 庫務會計師；會計主任 | [[dst|庫務署署長]] |
| 貿易主任 | 商務及經濟發展局常任秘書長 |
| 管理參議主任 | 副數字政策專員（數字政府） |
| 物料供應主任／員／助理物料供應員；政府車輛事務經理／主任 | 政府物流服務署署長 |
| 新聞主任 | 政府新聞處處長 |
| 統計師；統計主任；外勤統計主任 | 政府統計處處長 |
| 系統分析／程序編製主任；電腦操作員；資料處理員 | 數字政策專員 |

其餘人員由部門擬備及保存每年度報告。[[scs]]可隨時要求提交任何公務員的評核報告（第 234(2)–(3) 條）。

試用或試任人員：報告較密。試用人員在首年及第二年須按指定次數填寫（第 235(1) 條首句 OCR 殘，待核）；試任超過兩年者適用同一安排。確保依期填妥的人員，與第 234 條所列相同。

公務員離開所任職位前，須填妥屬員的評核報告或擬備工作表現便箋；屬員調離時，主管人員同樣適用（第 236 條）。距上次報告三個月內的人事變動，毋須提交；三至六個月以便箋；超過六個月用正式表格。此安排只適用於每年須接受評核的實聘人員。署理以待實際升職、試用或試任人員，分別按第 170(c) 及 235 條辦理。合約、借調或暫時調任期滿，所屬部門應向有關方面提交評核（第 237 條附近；字句殘）。

表格（第 238 條），除非[[scs]]批准其他方式：

| 對象 | 表格 |
| --- | --- |
| 薪酬在總薪級表第 45 點或以上 | 通用工作表現評核報告通用表格第 1 號 |
| 文書主任、文書助理、機密檔案室助理 | 公務員事務局表格第 90 號 |
| 辦公室助理員 | 公務員事務局表格第 93 號 |
| 電話接線生 | 通用表格第 95 號 |
| 私人秘書、打字督導、打字員 | 公務員事務局表格第 471 號 |
| 部門職系：總薪級第 34–44、28–33、16–27、10–15 點或同等 | 通用表格第 94A–94D 號 |
| 第一標準薪級 | 通用表格第 598 號 |
| 無適當部門表格的其他人員 | 通用表格第 95 號 |

部門如認為本身表格更適用，可用本身表格填寫部門職系報告；推出新表格或對現行部門表格作重大修改前，須獲[[scs]]批准。

評核報告歸類為「限閱文件（人事）」（附件 1.2）。由第 234 條所列主管當局保管。公務員調往另一部門時，先前報告應轉交新部門；存放在公務員事務局內者除外（第 239 條）。離任人員的服務紀錄（通用表格第 115 號）由對應職系首長或其轉授人員填寫；獲授權者其實任職級須較離職人員高一級或以上，職系最好相同或相關，亦可由部門／職系首長指派的首長級人員填寫。

評核檔旨在就品行及工作表現提供完整紀錄，除報告外亦應包括反映工作表現進退的其他文件。應存副本：書面警告；口頭警告紀錄；停止增薪及延期增薪通知書；任何正式紀律處分通知書；嘉獎信及贊賞信。來往詳細信件不應放入評核檔；考慮紀律、提升、停止增薪等的來往信件應存適當個人檔（第 240 條）。

## 服務證書與評核證書（CSR 第 241–243 條）

所有公務員，不論服務年期長短或工作表現如何，即使仍在政府服務，均可獲發服務證書（通用表格第 7 號）（第 241 條）。簽署者：

| 對象 | 簽署 |
| --- | --- |
| 部門職系 | 部門主任秘書或其轉授人員 |
| 一般職系 | 職系副首長或助理首長 |
| 政務職系 | 公務員事務局首席助理局長（政務職系） |
| 首長級 | 部門或職系首長 |
| 部門或職系首長本人 | [[scs]]安排簽發 |

評核證書（第 242–243 條）須絕對依據評核報告寫出工作表現和品行，不包括發證人的個人意見或推斷，亦不提職員協會或工會活動，不載詳細病歷。按該員要求或經其同意發出者，應以機密文件直接發給第三者（準僱主或教育機構），註明絕對保密、不得向未獲授權人士披露；該員要求時可讓其索閱。

首長級第 2 點或同級以下：由常任秘書長／部門首長／職系首長發給，可再轉授，但獲授權人員應通常與人事管理或行政有關；職級應比獲發證書者至少高兩級或相當於兩級；起薪點不應低於總薪級表第 34 點或同等。首長級第 2 點或同級以上：概由公務員事務局發出；申請時由常任秘書長／部門／職系首長連同擬稿送局。

曾被裁定刑事罪名成立（包括《防止賄賂條例》），或曾受正式紀律處分者，常任秘書長／部門／職系首長須先把擬稿連同評核檔及其他有關文件送[[scs]]批准。招致口頭或書面警告的輕微過失，通常不應在評核證書內反映；有疑問應徵詢公務員事務局。
