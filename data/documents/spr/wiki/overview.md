## One procurement lifecycle

```
Need + [[value-for-money]] + [[national-security]]
        → route: [[quotation]] / [[tendering]] / [[consultants-selection]] / [[direct-engagement]]
        → [[conflict-of-interest]] declarations
        → award by [[dtc]] / [[ctb]] / [[ccsb]] / [[pstsy]]
        → [[05-contract-admin|contract admin]] and [[contract-variation|variations]]
        → stores: [[07-accounting]] → [[08-stores-management]]
        → end of life: [[disposal]] / [[write-off]] / [[12-dangerous-confiscated]]
```

The fork that decides almost everything is **value and type**. See [[compare-procurement-routes]] and [[compare-approving-authorities]].

## Three structural facts

1. **Quotation vs tender is a value gate, not a quality judgement.** Stores / general services / revenue: quotation ≤ $1.35 million, departmental tender ≤ $10 million. Consultancy quotation ≤ $3 million. Works quotation ≤ $7 million; simplified non-WTO GPA works departmental limit $52 million (SPR 220; FC 3/2009).
2. **[[wto-gpa]] overlays extra rules** (notice period, limited-tender grounds, three-year file retention, Review Body) whenever the estimated maximum total value over the whole duration hits the GPA threshold. Do not split a requirement to dodge GPA (Appendix III(F)).
3. **[[national-security]] is a continuing duty** at every stage, any value (SPR 109A, 205A). Standard forms must allow disqualification and termination in the interest of national security (SPR 345(a)).
