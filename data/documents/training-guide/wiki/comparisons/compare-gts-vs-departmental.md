# 比較 — 政府培訓獎學金 vs 部門訓練

兩條軌道共用承諾書語言，不共用假期、貸款和部門角色。獎學金概念 [[gts]]；部門訓練表格 [[annex-1-non-gts]]；獎學金手續 [[annex-2-gts]]。

| | 部門訓練（獎學金以外） | [[gts\|政府培訓獎學金]] |
| --- | --- | --- |
| 目的 | 現職才能、效率、晉升、履職法定要求 | 取得資歷，加入招聘困難職系 |
| 假期 | 第 1000(1)／1001／1004 條，視課程 | **只有**第 1005 條無薪 |
| 資助入口 | 第 1001 條 → 第 1008 條；兼讀另走第 1010 條 | 第 1005 條 → 第 1008 條＋第 1009 條貸款豁免 |
| 免息薪金／房屋／教育貸款 | 無 | 有（在職公務員） |
| 配偶機票 | 無（問題 27） | 在職、港外、假期六個月以上：有 |
| 承諾書表格 | 附錄 1(d)–(f) | 附錄 2(i)，含接受新職系或回任 |
| 保證 | 保證人，或退休金抵銷，或先自費 | 保證人**加上**貸款擔保人 |
| 誰管 | 單一[[hod\|部門／職系首長]] | [[receiving-department\|接收]]＋[[parent-department\|所屬]] |
| 追討 | 該部門 | 按是否完成、是否已轉任新職系分家（第 3.45 段） |
| 受訓後去向 | 通常留在原職系 | 目標職系聘任，否則回任；未經[[csb\|局長]]批准不得轉其他職系 |

把第 3.46 段全薪格子裡的項目直接套到獎學金學員，會漏貸款和配偶機票，也會誤以為他們仍拿全薪。
