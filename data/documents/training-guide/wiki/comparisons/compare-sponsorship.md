# 比較 — 四格培訓資助

指引第 3.46 段把 CSR 第 1008 條資助畫成全薪 vs [[gts|獎學金]]、香港 vs 港外。首長不一定給齊。細節 [[training-sponsorship]]、[[03-sponsorship]]。

## 第 3.46 段表

| 項目 | 全薪・港外 | 全薪・香港 | 獎學金・港外 | 獎學金・香港 |
| --- | --- | --- | --- | --- |
| 課程及實習費用 | ✓ | ✓ | ✓ | ✓ |
| 最經濟來回機票 | ✓ | | ✓ | |
| 行李津貼（≥三個月） | ✓ | | ✓ | |
| 交通費 | ✓ | | ✓ | |
| [[subsistence-allowance\|進修津貼]] | ✓ | | ✓ | |
| 安頓額外假期 | ✓ | | ✓ | |
| 旅程時間額外假期 | ✓ | | ✓ | |
| 醫療福利 | ✓ | ✓ | ✓ | ✓ |
| [[council-tax\|市議會稅]] | ✓ | | ✓ | |

## 表外分叉

| 項目 | 全薪（第 1001 條） | 獎學金（第 1005 條） |
| --- | --- | --- |
| 配偶來回機票 | 否，不論假期長短（問題 27） | 在職條款：進修假期六個月以上可獲最經濟來回（附錄 2(c) B(ii)(f)） |
| 免息薪金貸款 | 無 | 實職薪金 50%，按月；完成受訓後服務後可豁免，變應課稅入息 |
| 房屋／教育津貼貸款 | 無 | 100%，按月 |
| 假期本身 | 全薪；計增薪和退休金服務期 | 無薪；不計增薪和退休金服務期 |

這不是 OCR 衝突：第三章表管「一般第 1008 條項目」，獎學金條款另給貸款和配偶機票。標 `contested: false`，但 query 時必須先問「是不是獎學金」。見 [[synthesis]]。

第 1002 條考試假期、第 1010 條發還學費、第 1004 條自行安排全日制，都不在上表。
