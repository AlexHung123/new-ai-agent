# 訓練債務與追討

未圓滿完成訓練或指定受訓後服務時，須償還政府已付或代付的訓練開支。CSR 第 1007 條把追討放在[[hod|部門／職系首長]]。什麼算債務見問題 22–24。

## 什麼算、什麼不算

| 算 | 不算 |
| --- | --- |
| 學費、旅費、[[subsistence-allowance\|進修津貼]] | 全薪進修假期期間的**薪金**（問題 22） |
| 暫駐實習：薪金貸款、房屋及教育貸款（問題 23） |  |

沒有提供任何受訓後服務 → 追討全部。已服務部分 → 按尚未完成服務的比例（第 3.40 段）。必須**一次過**清繳，不可分期（問題 24）。

計算表：附錄 1(j)（非獎學金）、2(p)（獎學金，另列薪金貸款及其他貸款）。可減：撫恤金計劃退款、未收貸款、其他退款。

## 程序（第 3.41–3.44 段）

1. 數額先交[[dst|庫務署署長]]核實，才發繳款通知書
2. 告知該員欠款數額，要求立即一次過清繳
3. 用盡辦法：催繳通知書、法律行動；需要時尋求律政司意見
4. 只在用盡其他方法後，才考慮從退休金扣除（會計通告第 3/2006 號）。查詢：庫務署退休金分部及／或公務員事務局退休事務及公積金組

## 獎學金誰追（第 3.45 段）

方法與其他訓練相同，但責任按學員身分分：

- 沒有完成訓練或沒有接受新聘任 → [[parent-department|所屬部門]]
- 公務員在接受新聘任後離職 → [[receiving-department|接收部門]]
- 學員並非公務員 → 接收部門
