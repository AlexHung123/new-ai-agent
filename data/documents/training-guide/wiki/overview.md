# 總覽 — 《公務員培訓事務指引》wiki

這是公務員事務局／[[civil-service-college|公務員學院]] 2021 年《公務員培訓事務指引》的編譯 wiki。原料是 `training_guide.md`（中文 PDF 轉出，約 2,100 行，OCR 殘缺）。你讀 wiki；代理人寫 wiki。查任何問題先讀 [[index]]，再只打開相關頁。

## 一條培訓路徑

```
才能要求 [[competency]] → 需要評估 → 周年計劃 [[training-framework]]
        → 選渠道：日間批假 / [[study-leave|進修假期]] / [[gts|獎學金]] / [[course-fee-reimbursement|發還學費]]
        → 批核 [[hod|部門／職系首長]]（例外見 [[csb]]）
        → 達門檻則簽 [[undertaking|承諾書]]＋[[surety-and-guarantee|保證／擔保]]
        → 發 [[training-sponsorship|培訓資助]]／[[subsistence-allowance|進修津貼]]
        → 受訓後服務；違約則 [[training-debt|追討]]
```

穿越全書的分叉軸是**假期種類**：CSR 第 1000(1) 條日間批假、第 1001／1002 條[[03-full-pay-study-leave|全薪進修假期]]、第 1004／1005 條[[03-unpaid-study-leave|無薪進修假期]]。對照 [[compare-study-leave]]。

## 三件結構事實

1. **這份指引解釋 CSR，不是取代 CSR。** 可執行的假期、承諾書、資助條文是 CSR 第 1000–1010 條；指引第三章告訴部門如何用。附錄 3 把這十一條重印一遍，見 [[annex-3-csr]]。
2. **「必需」與「有幫助」不是同一把鑰匙。** 全薪進修假期有四項批核理由（實任／履職／晉升／提升效率）。人員資格不足、或正履行承諾時，首長**只應**用前兩項（指引 第 3.6、3.9 段）。
3. **政府培訓獎學金是另一條軌道。** 假期改走 CSR 第 1005 條無薪；另有免息薪金／房屋／教育貸款、接收部門與所屬部門分工。不要把第三章 3.46 表的「全薪」格子套到獎學金學員。對照 [[compare-gts-vs-departmental]]。
