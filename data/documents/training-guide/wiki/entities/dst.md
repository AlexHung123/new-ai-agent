# 庫務署署長

培訓金錢流的執行當局：核實訓練費用、發放和扣減獎學金貸款、預支進修津貼、在最後手段才從退休金扣欠款。

## 在本指引出現的職能

| 職能 | 來源 |
| --- | --- |
| 核實訓練費用數額，然後才發出繳款通知書 | 指引 第 3.41 段 |
| 接收獎學金承諾書／保證書／擔保書副本 | 第 3.39 段 |
| 房屋津貼分部、薪金及津貼分部接收房屋及教育貸款擔保書副本 | 第 3.39 段 |
| 從學員所得貸款扣減欠款、附帶福利供款、撫恤金計劃供款（授權書附錄 2(o)） | [[annex-2-gts]] |
| 經部門申請預支最初 28 晚[[subsistence-allowance\|進修津貼]] | 附件 1 第 4 段 |
| 退休金分部：查詢從退休金／公積金扣除訓練費用（連同公務員事務局退休事務及公積金組） | 第 3.44 段 |

根據會計通告第 3/2006 號，各決策局／部門應只在用盡其他一切追討方法後，才考慮從退休金扣除欠款。見 [[training-debt]]。
