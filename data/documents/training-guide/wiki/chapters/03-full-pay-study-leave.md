# 全薪進修假期

指引 第 3.5–3.13 段。CSR 第 1001 條（獲提名的全職培訓）與第 1002 條（準備和參加考試）。概念頁 [[study-leave]]、[[examination-leave]]。

## 何時可批（第 3.5–3.6 段）

[[hod|部門／職系首長]]可批給獲提名的員工全薪進修假期，以便：

- 接受在香港辦、**超過連續一星期**的全日制訓練；或
- 參加在香港以外地方辦的課程。

批核理由須屬下列之一（第 3.6 段）：

| | 理由 |
| --- | --- |
| A | 實任現時職級所必需 |
| B | 有效履行現時職務所必需（例如符合與職務有關的法定要求） |
| C | 晉升所必需 |
| D | 有助提升工作效率 |

如審批的全薪進修假期需要按 CSR 第 1006 條簽署[[undertaking|承諾書]]，首長應特別考慮：訓練必須與部門／職系工作密切關連，並配合部門／職系工作目標和重點（第 3.7 段）。

## 必須徵詢決策局（第 3.8 段）

特別在下列情況，部門／職系首長**必須**徵詢所屬決策局：

- 員工獲提名參加並非其部門／職系所屬範疇的專業培訓
- 涉及的全薪進修假期為期**六個月或以上**

## 人員資格（第 3.9 段）

按第 1001 條獲批的員工應：

- 已是常額編制人員；**或** 2000-06-01 或以後按新入職制度受聘並已完成試用期；**或** 合約人員並已完成最少一個合約任期（常額／合約人員的合約期應覆蓋受訓後服務期）
- 具備良好的服務記錄
- **並非**正在履行任何受訓後服務承諾

否則，首長只應基於第 3.6A 或 3.6B 段批給。問題 8、9 用同一規則。這不是絕對禁止，是收窄理由。見 [[synthesis]]。

**不可**批全薪進修假期讓員工參加自行安排的課程（問題 14）。

## 對服務條件的影響（第 3.10–3.12 段）

| 項目 | 全薪進修假期（第 1001 條） |
| --- | --- |
| 增薪、年資、可享退休金服務期 | 計算 |
| 賺取假期 | 否 |
| 旅費資格周期 | 不算入 |
| 合約人員現有合約 | 按進修假期延長 |
| 署任、逾連續一星期全日制 | 受訓期間**停止署任** |
| 署任、不超過連續一星期全日制 | 可繼續收取署任津貼（如適用） |

賺假／旅費總表見 [[compare-study-leave]]（問題 10）。

港外受訓：即使受訓期內有香港公眾假期，缺勤期間仍批全薪進修假期（問題 11）。因個人理由離開受訓地方須首長批准；首長決定是否改放例假（問題 12）。若環境不容許受訓完畢立刻返港，等候最早回程航班的時間亦算全薪進修假期，並有資格獲[[subsistence-allowance|進修津貼]]（問題 13）。

## 考試全薪進修假期（第 3.13 段）

部門／職系首長可按 CSR 第 1002 條批給全薪進修假期，以準備和參加考試，考取的資格須與其職務或所屬部門的職務有關。比率與 12 個月上限見 [[examination-leave]]。第 1002 條假期**不**享有 CSR 第 1008 條培訓資助（問題 19）。
