# 發還課程及考試費用

指引 第 3.50–3.53 段。CSR 第 1010 條。這是**自行安排**的兼讀、短期或函授軌道，不是第 1001 條全薪提名，也不是[[gts|獎學金]]。概念頁 [[course-fee-reimbursement]]。

## 條件（第 3.50 段）

視乎部門資源和優次，[[hod|部門／職系首長]]可發還學費和考試費用或其任何部分，條件是：

| | 條件 |
| --- | --- |
| A | 通常為常額編制人員，或已完成一個合約任期（2000-06-01 或以後按新入職制度聘用者必須已完成試用期） |
| B | 課程與該員本身工作有關 |
| C | 發還申請在**課程開始前**提交 |
| D | 能證明修業期滿考試及格；無須考試則須證明有 **70%** 或以上上課率 |

可發還全部或部分（問題 41）。香港以外地方的短期課程也可走第 1010 條（問題 42）。

## 範圍（第 3.51–3.52 段）

- 只發還**一個學年**的學費和考試費用。其後學年須於每個新學年開始時重新申請。
- 不獲發還：申請費用、保證金、住宿課程費用、交通費。
- 單元課程：只發還與職務有關的單元。

## 時間（第 3.53 段）

自行安排的課程須用自己的時間修讀（辦公時間內舉行則須申請放取假期）。辦公時間以外修讀，不享有逾時工作津貼或補假。

## 與其他資助不可雙重領取

每項課程只可接受一個來源的資助。已接受某項政府資助計劃，即沒有資格再申領第 1010 條。單元課程可按單元選擇不同來源（問題 43）。

已借貸修讀**不算**已接受資助，仍有資格申領第 1010 條（問題 44）。
