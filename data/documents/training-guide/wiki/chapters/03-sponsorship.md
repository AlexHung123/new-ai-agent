# 培訓資助

指引 第 3.46–3.49 段。CSR 第 1008 條：按第 1001 條獲批全薪進修假期，或按第 1005 條獲[[gts|政府培訓獎學金]]而無薪進修假期的員工，可獲培訓資助。批核人員為[[hod|部門／職系首長]]。對照表 [[compare-sponsorship]]；細則 [[training-sponsorship]]、[[subsistence-allowance]]、[[council-tax]]。

## 資助矩陣（第 3.46 段）

| 項目 | 全薪・港外 | 全薪・香港 | 獎學金・港外 | 獎學金・香港 |
| --- | --- | --- | --- | --- |
| 課程及實習費用 | ✓ | ✓ | ✓ | ✓ |
| 最經濟來回機票 | ✓ | | ✓ | |
| 行李津貼（訓練三個月或以上） | ✓ | | ✓ | |
| 交通費 | ✓ | | ✓ | |
| 進修津貼 | ✓ | | ✓ | |
| 安頓額外假期 | ✓ | | ✓ | |
| 旅程時間額外假期 | ✓ | | ✓ | |
| 醫療福利 | ✓ | ✓ | ✓ | ✓ |
| 英國市議會稅 | ✓ | | ✓ | |

首長不一定給予全部項目；是否適用視個案而定（第 3.46 段註）。

這張表**沒有**配偶機票，也**沒有**薪金貸款。配偶機票：全薪港外一律不發（問題 27）；獎學金在職條款於進修假期六個月以上可發（附錄 2(c)）。薪金貸款只走第 3.48 段獎學金軌道。見 [[synthesis]]。

## 細則摘要（第 3.47 段）

- 受訓地點多於一個，可視乎需要批額外機票。因個人理由改期或提升艙等，須首長批准並自付差額（問題 26）。
- 行李津貼：實報實銷；航空及／或海路運費、私人物品保險。預先申請不受理（問題 29）。包裝箱、公事包不發還。短期課程攜帶必需器材，首長可把超重行李列作雜項（問題 30）。
- 交通費不包括每日住所往返通常上課地點。包括往來住所／受訓地方與機場的公共交通、機場稅、簽證費。計程車一般不發還，抵達或離開時安排不到最經濟交通工具可特別批准。
- 進修津貼按在受訓地方度過的每晚發放；安頓以外的其他假期，或離開受訓地方（除非是課程一部分），不發。比率 [[subsistence-allowance]]。
- 港外不論地點，訓練開始前一天安頓期，以曆日計算。
- 最直接路線旅程時間算進修假期，但旅程期間不獲進修津貼。抵港當日屬旅程時間，當日不用上班（問題 37）。
- 港外醫療：衛生署署長認為治療必需且費用合理（CSR 第 912 條）。訓練機構規定購買醫療保險才發還保費（問題 38）。緊急牙科在同一條件下可發還（問題 39）。
- 英國市議會稅見 [[council-tax]]。

## 獎學金免息貸款（第 3.48 段）

按第 1005 條獲獎學金並批無薪進修假期的員工，整段無薪期可獲免息貸款：按月發放，數額相等於**實職薪金的 50%** 及**房屋和教育津貼的 100%**。圓滿完成受訓後服務後，首長可豁免償還免息薪金貸款（CSR 第 1009 條）。豁免後該筆貸款視為應課稅入息，須通知稅務局局長。

## 體格檢查（第 3.49 段）

將於香港以外地方受訓**超過 12 個星期**的員工（第 1001 或 1005 條），首長須安排體格檢查。詳情見 2000-08-30 公務員事務局通函第 20/2000 號。

## 因公受傷（問題 40）

按 CSR 第 1000 條獲批假，或按第 1001 條獲提名參加訓練，且符合《僱員補償條例》準則，一般視作因公受傷。依有關通告和 CSR 處理，並盡早向首長報告。
